# Study Board

A minimalist, customizable productivity dashboard featuring floating apps, ambient sounds, background presets, and focus tools—perfectly tailored for iPad & tablet study workflows.

**Live Demo:** [Click here to open the Study Board](https://Annicat3.github.io/Study-Board/)


## Features
- **To-Do List:** LocalStorage-powered task manager to track your daily goals.
- **Focus Timer:** Clean countdown timer with a browser alert.
- **Notes:** Dynamic notepad that automatically scales and saves your thoughts.
- **Ambient Soundboard:** Individual volume sliders for custom focus audio mix.
- **Dynamic Backgrounds:**
  - Custom image uploads
  - Curated **Unsplash** preset wallpapers
  - Interactive **YouTube** video background support
-  **Cat & Quote Generator:** A fun widget powered by external APIs (**CATAAS** & **DummyJSON Quotes**) for study motivation.
-  **Live Date & Time Display:** Real-time clock with full day and month formatting.
-  **Accent Color Personalization:** Dynamic text & UI color contrast adjustments.


## Tech Stack

- **HTML5** (Structure & Native Drag API)
- **CSS3** (Flexbox, Dynamic Viewport Units `dvh`, Custom Properties)
- **JavaScript (Vanilla ES6+)** (DOM Manipulation, LocalStorage, Fetch API)


##  iPad & Desktop Compatibility

> **Note for Desktop Users:**
> This application was designed, built, and optimized **specifically for iPad screens**. While basic desktop drag-and-drop support is implemented for testing on laptops, the UI and touch interactions shine best on a tablet device in lanscape orientation.
